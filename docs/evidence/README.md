# Evidence

This directory holds sanitized release evidence: screenshots, the scrubbed
test log (`phase1/test-output.txt`, path-scrubbed by `scripts/test.sh`), and
live-run summaries (`phase2/live-matrix.md`, `phase3/live-l6.md`).

Raw live evidence — native session ids, provider transcripts, and live JSON
dumps — is intentionally **not committed**. It is retained outside the
repository on the originating Mac. Summaries and screenshots document what was
observed without exposing account or session identifiers.
