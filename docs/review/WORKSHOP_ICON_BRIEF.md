# Workshop icon

Built-in Image Generation tool; original asset inspected and placed in the web preview. Master: community-standalone/assets/workshop-icon.png, 1254×1254 PNG with alpha. No installed app icon changed.

Final generation prompt:

> Use case: logo-brand. Asset type: finished macOS app icon for Workshop, a collaborative workspace for four AI engineers. Create one polished app icon, front-facing, square 1024x1024 composition. A deep aubergine rounded-square tile with a beautifully crafted interlocking W mark made of four broad folded satin ribbons: orchid, lavender, pale lilac, a restrained mint accent. The interlocking form should suggest people working together at one table, with clean negative space, recognizable at small dock size. Sophisticated dimensional material, subtle bevel and soft studio lighting, crisp silhouette, restrained depth, no busy details. Tile occupies most of the image with a small transparent margin; genuinely transparent outside the rounded square. No words, no extra symbols, no mockup scene, no watermark. Match a purple Slack-inspired desktop productivity app while being an original Workshop brand, not Slack's logo.

The tool returned 1254×1254 rather than the requested prompt dimensions. Preserve the master; generate platform-size assets and inspect 16/32/64px legibility during later packaging. Native .icns/app integration is deferred with the Electron migration.
