# Workshop — community web design preview

This is the authoritative preview for the approved purple reference. It is dependency-free and uses no live model/API connection.

Run from this folder:

```sh
python3 -m http.server 4175 --bind 127.0.0.1
```

Open http://127.0.0.1:4175 . Or open index.html directly; all scripts/assets are local.

Try the main task's five tabs, then the small checkout-label task. Ownership → Team capacity exposes Unknown telemetry and a clearly labeled low-capacity scenario. Creating tasks/replies affects only in-memory demo data. Refresh resets it.

See design-qa.md for actual computer-use verification. See ../WORKSHOP_COMMUNITY_DESIGN.md for Codex ingress findings, Electron migration implications and implementation acceptance criteria.

The icon master is assets/workshop-icon.png (1254×1254 PNG, alpha channel). It is a generated original design; resized iconsets/.icns packaging have not been produced or installed. Standard control assets were exported from the macOS SF Symbols available on this machine.
